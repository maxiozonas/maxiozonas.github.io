# React Bits adaptations

Source: [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits), retrieved 2026-10-09. The upstream MIT + Commons Clause license is retained in `LICENSE.md`.

- `MagicBento.tsx`: retained but no longer rendered on the homepage, which now uses `../ProjectIndex.tsx`. Derived from `src/ts-default/Components/MagicBento/MagicBento.tsx`, with real portfolio content, scoped GSAP pointer effects and reduced-motion support.
- `SplitText.tsx`: upstream `src/ts-default/TextAnimations/SplitText/SplitText.tsx`, with a reduced-motion guard and ARIA correction for span tags. The hero provides an unsplit accessible heading. Uses GSAP SplitText and `@gsap/react`.
- `ScrollReveal.tsx`: derived from `src/ts-default/TextAnimations/ScrollReveal/ScrollReveal.tsx`. Preserves scrubbed word opacity, fixes nested heading/paragraph markup, adds accessible text and only reverts its own GSAP context. Removes blur.
- `Magnet.tsx`: derived from `src/ts-default/Animations/Magnet/Magnet.tsx`. Preserves pointer attraction with GSAP refs rather than per-frame React state; listens only within the button wrapper.
- `GhostFibers.tsx` and CSS: retained but unused after the Light Rays replacement. Upstream `src/ts-default/Backgrounds/GhostFibers/`, with a neutral backdrop, visibility handling, reduced-motion and capped frame rate.
- `SplashCursor.tsx`: retained but unused. Upstream `src/ts-default/Animations/SplashCursor/SplashCursor.tsx`, with fluid simulation, resource cleanup, visibility handling and an idle stop. The current site does not import, load or render the smoke effect.
- `LightRays.tsx` and CSS: installed using the official `@react-bits/LightRays-TS-CSS` registry on 2026-10-28, then moved into this directory. Preserves the original WebGL2 volumetric light shader, pointer steering and cursor shadow from [Light Rays](https://reactbits.dev/backgrounds/light-rays). Adds a 30fps cap, ready/theme markers, visibility handling and context cleanup. The wrapper disables click pulses, pulsation and intro; blue/lime rays enter diagonally from the top-right. `../Atmosphere.tsx` lazy-loads it only for fine-pointer desktop devices with motion enabled; palettes update without recreating the canvas. CSS selects actual shader captures for mobile, reduced motion, no JavaScript or unavailable/lost WebGL. `scripts/capture-atmosphere.mjs` regenerates them. No dependencies are needed; scroll animations are unchanged.
- `ScrollStack.tsx`: adapts the stacking composition from `src/ts-default/Components/ScrollStack/ScrollStack.tsx` to document scrolling, CSS sticky positioning and GSAP scale scrubbing. `../ExperienceChapters.astro` supplies full-width, transparent editorial chapters instead of inset cards, revealing the shared Light Rays atmosphere. The outgoing chapter scales to 0.96 and fades before incoming text can overlap it. Padding and sticky bounds are measured during refresh; there are no per-frame geometry reads. A desktop-only handoff gap allows the chapter to be read before fading. `data-stack-motion` gates sticky positioning and spacing until hydration; no-JavaScript views never stack transparent text. Scrolling back restores the outgoing content, and reduced motion restores opacity/visibility as well as transforms. Avoids the original nested scroll container and Lenis smoothing engine. Mobile and tablet use ordinary document flow; no sidebar pinning remains.
- `../PortfolioNav.tsx`: borrows Pill Nav's expanding circular hover fill. The navigation itself uses genuine shadcn Base UI NavigationMenu and Sheet, rather than the React Bits demo's router dependency and manual mobile overlay.

Brand tokens are defined centrally in `src/styles/global.css`. The six technology folders have their own muted category colours, while the rest of the site retains its lime identity.

- `SpotlightCard.tsx` and CSS: retained but no longer rendered by the homepage. Upstream `src/ts-default/Components/SpotlightCard/`, with semantic theme tokens, disabled press flares and reduced light intensity. The WebKit mask assignment uses `setProperty` for compatibility without deprecated DOM types.

The hero now uses the name as its visual: one wide line on desktop, two on mobile, with an accent-coloured surname. `../HeroTitle.tsx` takes inspiration from [Text Pressure](https://reactbits.dev/text-animations/text-pressure)'s pointer-proximity interaction, but does not use its variable-font implementation. Local GSAP `quickTo` transforms gently stretch/lift glyphs in the existing self-hosted Cabinet Grotesk. There is no idle loop or new font/dependency. Live reduced-motion preferences and fine-pointer/desktop media queries govern the interaction; the accessible name remains unsplit HTML. Technology marks sit in six interactive coloured folders. Light mode uses cool grey-white surfaces and slate; dark mode uses slate-black and orange. Light Rays supplies the shared interactive background in both modes.

- `../DotGrid.tsx` and CSS: installed from the official `https://reactbits.dev/r/DotGrid-TS-CSS.json` registry on 2026-10-14 using the shadcn CLI. Retained as an unused component after replacing the hero's dot background.
- `../HeroArtwork.tsx` and `../hero-constellation.ts`: retained but unused original Canvas 2D/SVG sphere, inspired by the public [Astral Shell preview](https://pro.reactbits.dev/docs/components/astral-shell). No Pro source is used. It is not imported or rendered by the current homepage.

- `AnimatedContent.tsx`: adapted from `src/ts-default/Animations/AnimatedContent/AnimatedContent.tsx`. Keeps GSAP/ScrollTrigger entrance motion, renders visible static HTML, scopes cleanup to its media context and honours live reduced-motion changes.
- `FolderFloat.tsx` and CSS: adapted from `src/ts-default/Micro/FolderFloat/`. Preserves the folder silhouette, perspective flap and staggered spring reveal. Extends text items to real technology marks, replaces the physics engine and continuous drift with stable CSS positions, and uses named native `details` for exclusive opening with keyboard, touch and static HTML support. A click after hovering keeps the folder open; Escape closes it and restores focus. Peek papers show two logos, selecting a mark reveals verified work links, and reduced motion removes transitions.
- `../WorkSteps.tsx` and `../WorkScene.tsx`: the five working stages as an editorial list. The row interaction (full-width rows of large type that react to hover) borrows from `src/ts-default/Components/FlowingMenu/`, without its marquee: the open row unfolds with a `grid-template-rows` transition and shows the stage text, its outcome and an animated SVG glyph with no text (points that sort themselves, a plan being drawn, blocks filling it, a piece travelling to its target, an orbit that keeps turning). Hover, click, focus and the up and down arrow keys open a row. The root gets `data-js` from the inline script in `Base.astro`, so the list is already collapsed before hydration; without JavaScript every row is open.
- `Topography.tsx` and CSS: upstream `src/ts-default/Backgrounds/Topography/`, retrieved 2026-11-12 and unmodified. `../HeroBackdrop.tsx` lazy-loads it as the hero background with the brand colour, fewer lines, low glow and opacity, no click pulse, and a capped pixel ratio. It is a full-bleed layer masked to fade out at the bottom of the hero. While the hero is on screen `data-hero-view` on the root fades the shared Light Rays layer out, so the two effects never overlap; Light Rays returns for the rest of the page and on project pages.
- `FolderFloat` closing: `::details-content` transitions `content-visibility` so the marks fly back into the folder instead of vanishing when the pointer leaves. The project list for the hovered technology is a floating card under the folder on desktop (no layout shift) and stays in the flow on mobile.
- Projects index: project names use the same large type as the working stages (from 768px), so the section carries equal weight. Food Partners shows captures of its institutional site (taken from a local build of `XenovaDevs/food-partners-landing`); the ERP is internal, so the case page describes it by area instead.
- `../ProjectWall.tsx` and CSS: adapted from `src/ts-default/Backgrounds/GridMotion/` (tilted rows of tiles drifting in alternate directions). Tiles are project captures linking to their case page; hovering one brakes the rows, straightens and enlarges that card and shows its name and a call to action. The wall is shown from 1200px with a fine pointer and motion enabled, is hidden from assistive technology and the tab order, and the project index underneath collapses to one line of names that opens the matching card on hover or focus. Everywhere else (narrower screens, touch, reduced motion, no JavaScript) the index with its preview panel is the layout, unchanged.

- `../ExperienceBadges.tsx` and CSS: independent of React Bits (the idea follows its `Lanyard` component, without three.js or physics). The two current roles are staff badges on lanyards, built with CSS: they sway, lean towards the pointer, and the selected one hangs lower. Badges are tabs; the role panel beside them lists scope, stack and, for Xenova, links to its client projects. `#experience-<id>` links select the matching badge. `ScrollStack.tsx` is no longer rendered. Without JavaScript both roles are listed in full.
- `../CertificateStack.tsx` and CSS: education and languages as a pile of certificates next to their text. The tap-to-send-back interaction follows `src/ts-default/Components/Stack/`; with a mouse the pile fans out on hover instead (CSS only). It mirrors the list beside it, so it is hidden from assistive technology.
- `../ContactEmail.tsx`: the contact section closes the page with the address in large type, sized to the column with container units, using the same pointer effect as the hero name (`src/lib/glyph-pressure.ts`, shared by both). The address is a plain `mailto:` link and a button copies it.
